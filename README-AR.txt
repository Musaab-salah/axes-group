AXES GROUP - الموقع من كمبيوتر المكتب عبر IP

1. فك ضغط الحزمة في مجلد ثابت على جهاز المكتب بنظام Windows.
2. تأكد أن Python 3 مثبت. للتحقق: افتح CMD واكتب py -3 --version
3. افتح PowerShell بصلاحية Administrator، وانتقل إلى مجلد الحزمة ثم شغّل مرة واحدة:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\allow-office-network.ps1
   هذه القاعدة تسمح بالوصول إلى منفذ 8765 من شبكة المكتب الخاصة فقط.
4. انقر مرتين على start-ip-site.cmd. سيظهر رابط مثل:
   http://172.16.2.151:8765
   استخدم الرقم الذي يظهر على شاشة جهازك، فقد يختلف عن المثال.
5. افتح الرابط على هاتف متصل بنفس Wi-Fi للمكتب للتحقق. اترك نافذة التشغيل مفتوحة.

لوحة الإدارة CMS (إدارة المحتوى):
1) تأكد أن Node.js مثبت.
2) مرة واحدة داخل مجلد cms:
   npm install
   npm run db:setup
3) للتشغيل المحلي فقط:
   cd cms
   npm run start
   ثم افتح http://127.0.0.1:8765/admin
4) للدومين العام (axessud.com) استخدم start-domain-site.cmd
   (يشغّل CMS على 8765 + Cloudflare Tunnel)
5) بيانات الدخول الابتدائية (غيّرها فورًا):
   البريد: admin@axessud.com
   كلمة المرور: ChangeMeNow!2026

ما يعمل الآن في CMS:
- تسجيل دخول آمن + صلاحيات أدوار
- لوحة تحكم بإحصاءات حقيقية
- تعديل نصوص الرئيسية ومن نحن (عربي/إنجليزي)
- حفظ مسودة ثم نشر
- رفع وسائط أساسية
- ظهور المحتوى المنشور على الموقع العام دون كسر التصميم

ما لم يُكمل بعد (مراحل لاحقة):
- محرر مرئي بنمط Webflow كامل
- إدارة صفحات/مشاريع/خدمات/قوائم متقدمة كاملة
- SEO/نسخ احتياطي/صلاحيات مستخدمين موسّعة في الواجهة

ربط الدومين axessud.com (رابط ثابت دائم):
ملاحظة: الدومين حالياً على OrderBox. يلزم نقله إلى Cloudflare مرة واحدة.
1) أنشئ حساباً مجانياً على https://dash.cloudflare.com إن لم يكن لديك.
2) Add a site → أدخل axessud.com → أكمل حتى تظهر Nameservers.
3) من لوحة OrderBox غيّر Nameservers للدومين إلى القيم التي أعطتك إياها Cloudflare.
4) انتظر حتى يظهر في Cloudflare أن الدومين Active (دقائق إلى ساعات).
5) على جهاز المكتب انقر مرتين: setup-axessud-domain.cmd
   (يفتح متصفحاً لتسجيل الدخول Cloudflare، ثم ينشئ النفق ويربط axessud.com و www).
6) بعد نجاح الإعداد شغّل دائماً: start-domain-site.cmd
7) افتح https://axessud.com — اترك النافذة مفتوحة طالما تريد الموقع متاحاً على الإنترنت.

للوصول المؤقت بدون دومين (رابط يتغيّر - Cloudflare Tunnel):
1. انقر مرتين على start-site.cmd
2. انتظر ظهور رابط يبدأ بـ https://....trycloudflare.com
3. انسخ الرابط وافتحه من أي شبكة أخرى (الجوال ببيانات الجوال، منزل، إلخ)
4. اترك نافذة التشغيل مفتوحة؛ عند إغلاقها يتوقف الرابط العام.
ملاحظة: الرابط يتغيّر في كل تشغيل (رابط مؤقت للعرض/الاختبار).

للوصول من خارج المكتب عبر IP عام (بدون Cloudflare):
- عنوان 172.16.x.x أو 192.168.x.x يعمل داخل الشبكة فقط، ولا يصل إليه عميل من الإنترنت.
- تحتاج إلى Public IPv4 على راوتر المكتب (بدون CGNAT)، ويفضل عنوان ثابت من مزود الخدمة.
- ثبّت IP داخليًا للجهاز، ثم اضبط Port Forwarding على الراوتر: TCP 8765 إلى IP الجهاز الداخلي على TCP 8765.
- بعد ذلك يلزم تعديل قاعدة Windows Firewall للسماح للزوار الخارجيين أيضًا، وفق سياسة شبكة المكتب.
- الرابط سيكون http://PUBLIC-IP:8765 ويعمل فقط ما دام الجهاز والإنترنت والتوجيه والمنفذ متاحين.
- اتصال HTTP عبر IP مباشر غير مشفّر. للنشر النهائي استخدم دومينًا وHTTPS مع إعداد استضافة مناسب.

الموقع صفحات ثابتة؛ نموذج التواصل يفتح برنامج البريد لدى الزائر ولا يحفظ الطلبات على جهاز المكتب.
